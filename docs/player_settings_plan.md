# 재생·화면 설정 계획서 (Plexamp 설정 검토)

- **작성일:** 2026-10-31
- **상태:** 계획 (구현 전)
- **참고:** 사용자가 보내 준 Plexamp 설정 화면 11장 (설정, 계정, 사용자 경험, 플레이어, 재생, 퀄리티, 원격 제어, 자동재생, 캐싱, 라이브러리, 홈)

## 1. 먼저 알아 둘 제약

muzplayer는 브라우저(PWA)에서 `<audio>` 요소 하나로 재생한다. Plexamp는 네이티브 앱이다. 그래서 같은 설정이라도 브라우저에서는 되는 것과 안 되는 것이 갈린다.

| 제약 | 영향 |
|---|---|
| **iPhone은 웹 페이지가 음량을 바꿀 수 없다** (`audio.volume` 무시) | 음량 레벨링·크로스페이드를 음량 조절로 할 수 없다. Web Audio를 쓰거나 서버에서 처리해야 한다. |
| **iPhone에서 Web Audio로 소리를 돌리면** 화면이 꺼졌을 때 재생이 끊길 수 있다 | EQ·레벨링·크로스페이드는 iPhone에서 기본으로 끄고, 켤 때 경고를 띄운다. 또는 서버 처리로 한다. |
| **서버 이미지에 ffmpeg가 없다** | 비트레이트 변환(퀄리티)을 하려면 ffmpeg를 넣어야 한다. 이미지가 약 40~80MB 커지고, DS218+(듀얼코어)에서 동시 변환은 2~3개가 한계다. |
| **Wi-Fi·모바일 데이터 구분** | Android 크롬만 알려 준다(Network Information API). iPhone은 모른다 → "이 기기 설정" 하나로 단순화한다. |
| **설정 저장 위치** | 화면·기기 관련은 지금처럼 브라우저마다(localStorage), 사람에 따른 것(기록 남기기 등)은 서버 계정에 저장한다. |

### 재생

| Plexamp 설정 | 판정 | muzplayer에서 | 방법 |
|---|---|---|---|
| 오디오 출력 | 🟡 | 출력 장치 고르기 | `audio.setSinkId()` — PC 크롬·엣지만. PC 전용 메뉴로 |
| 퀄리티 | 🟡 | 스트리밍 품질: 원본 / 320 / 192 / 128kbps | 서버에 ffmpeg 추가, `/stream?bitrate=`로 그때그때 변환(AAC). 밖에서 모바일 데이터로 들을 때 유용. 변환은 동시 2개로 제한 |
| 음량 레벨링 | ✅ | ReplayGain으로 곡마다 소리 크기 맞추기 | 태그의 `replaygain_track_gain`은 이미 `tag_json`에 저장되고 있다. PC·안드로이드는 Web Audio 게인, iPhone은 서버에서 게인 적용(ffmpeg 필요) 또는 끔. 태그 없는 곡은 그대로 |
| 스위트 페이즈 (크로스페이드) | 🟡 | 곡 사이 2~8초 겹쳐 넘기기 | `<audio>` 두 개를 번갈아 쓰고 음량을 교차. iPhone은 음량 제어가 안 돼 Web Audio 필요 → 화면 꺼짐 문제. PC·안드로이드 전용으로 시작 |
| Downmix to Stereo | ❌ | | 브라우저가 알아서 스테레오로 낸다. 서버 변환을 넣으면 그때 같이 처리 |
| EQ | 🟡 | 10밴드 이퀄라이저 + 프리셋 | Web Audio `BiquadFilter` 10개. iPhone 제약 동일 → PC·안드로이드 전용 |
| 원격 제어 | 🟡 | 다른 기기에서 지금 재생 중인 기기 조종(휴대폰으로 PC 재생 조종) | 서버에 WebSocket을 두고 같은 계정의 기기끼리 명령을 주고받는다. 규모 큼 |
| 라디오 | ✅ | 아티스트·곡 라디오: 비슷한 곡 끝없이 | 같은 아티스트·장르·연대·별점으로 고르는 서버 API(`/radio?seed=`). 믹스 코드를 재사용 |
| 자동재생 | ✅ | 아래 "자동재생" |

## 3. 설정 화면 구성안

Plexamp처럼 설정을 묶음으로 나눈다. 지금 설정 화면(언어·테마·오디오북·계정)을 다음과 같이 바꾼다.

```
설정
├── 화면          테마, 언어, 홈 화면 줄, 코덱 배지, 앨범 연도, 음량 막대(PC)
├── 플레이어      재생 시 재생 화면 열기, 화면 켜짐 유지, 재생 속도, 막대 모양
├── 재생          음량 레벨링, 크로스페이드, EQ, 출력 장치(PC), 스트리밍 품질
├── 자동재생      켜기, 앨범이 끝나면, 재생 기록 남기기
├── 저장 공간     다음 곡 미리 받기, 캐시 크기, 캐시 지우기, 오프라인 저장한 앨범
├── 오디오북      (지금 있는 것)
└── 계정          (지금 있는 것)
```

휴대폰은 한 줄짜리 목록(제목 + 설명 + 값 + ›)으로, 누르면 하위 화면으로 들어간다. PC는 왼쪽에 묶음 목록, 오른쪽에 내용을 둔다.

## 5. 정해 주셔야 할 것

1. **우선순위:** 위 단계 순서대로 괜찮은지, 먼저 원하는 항목이 있는지.
2. **iPhone 사용 비중:** 주로 iPhone이면 4단계(EQ·레벨링·크로스페이드)는 화면이 꺼지면 끊길 위험이 있어 5단계(서버 처리)와 묶어야 한다.
3. **ffmpeg 추가:** 이미지가 커지고 NAS CPU를 쓴다. 밖에서 모바일 데이터로 자주 듣는다면 가치가 있다.
4. **0.5점 별점:** 필요한지.
