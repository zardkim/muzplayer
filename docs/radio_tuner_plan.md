# 라디오 튜너 모드 계획서

- 작성: 2026-11-12 (muzplayer 0.63.5 기준) · 같은 날 디자인 수정(iPhone FM 라디오 앱 방식)
- 목표: 라디오 페이지에 지금의 **목록 모드**와 함께, 다이얼을 돌려 듣는 **튜너 모드**를 둔다. 주파수·채널·채널 이미지·지금 방송 프로그램을 표시하고, 탐색(SEEK·SCAN)과 메모리(프리셋) 기능을 넣는다.
- 디자인: iPhone FM 라디오 앱 같은 깔끔한 레이아웃(큰 주파수 숫자 + 가로 눈금 다이얼 + 가운데 바늘)에 앱 테마를 적용한다(2026-11-12 수정).

## 1. 지금의 라디오 (출발점)

| 항목 | 현재 |
|---|---|
| 방송국 | `backend/app/radio_stations.json` 181곳. 지역(서울 37, 부산 37, 광주 32 …)별로 묶여 있음 |
| 재생 | 서버가 각 방송국 인터넷 스트림을 중계(`radio.py`), 앱은 `player.playStation()` |
| 화면 | `RadioView.vue`: 지역 선택, 목록/카드 보기, 즐겨찾기·최근, 숨기기, 내 방송국 추가 |
| 저장 | `ui.radio`(즐겨찾기·최근·숨김), 계정에 동기화(`prefsSync`) |
| **없는 것** | **주파수 정보가 없다.** 튜너 모드의 핵심 데이터라 먼저 채워야 한다 |

> 실제 전파를 받는 것이 아니라 인터넷 스트림이다. 튜너는 "주파수 = 그 지역 방송국의 스트림"으로 바꿔 주는 화면이다. 다이얼이 방송국 사이에 있을 때는 재생을 멈추고, 원하면 작은 튜닝 잡음을 들려준다.

## 2. 주파수 데이터 (1단계, 먼저)

### 2.1 저장 형식
`radio_stations.json`의 방송국마다 지역별 주파수를 넣는다. 같은 방송국이라도 지역마다 주파수가 다르기 때문이다.

```json
{ "id": "kbs-2fm", "name": "KBS 2FM", "regions": ["seoul"], "freq": { "seoul": "FM 89.1" } }
{ "id": "kbs-hanminjok", "name": "KBS 한민족방송", "regions": ["seoul"], "freq": { "seoul": "AM 972" } }
```
(구현: 지역별 `"FM 89.1"` / `"AM 972"` 문자열. 0.64.0에서 174곳 입력, 주파수를 확인하지 못한 39곳(인터넷 전용, 일부 공동체 라디오, 부산·전북 국방FM, TBN 충남)은 NET 밴드. 한 지역에서 두 방송국이 같은 주파수면 둘 다 그 자리에 두고 튜너에서 "같은 주파수: …"로 바꿔 듣는다.)

- 밴드: **FM**(88.0–108.0 MHz, 0.1 단위), **AM**(531–1602 kHz, 9 단위).
- FM·AM 동시 송출(예: KBS 1라디오)은 대표 하나를 정한다. 기본은 FM이 있으면 FM이다.
- 주파수가 없는 방송국(인터넷 전용: MBC mini 올댓뮤직, SBS 고릴라디오M, EBS 반디, 내 방송국)은 **NET 밴드**에 채널 번호로만 놓는다.

### 2.2 수집 방법
- 영어 위키백과 "List of radio stations in South Korea"(방송사·지역별 주파수 목록)를 기본으로, 한국어 위키백과 방송사 문서의 송신소 표(TBN, 극동방송, BBS, 평화방송, 원음방송, 국악방송, 국방FM, AFN)로 보완했다(2026-11-12).
- 서울 기준 예시(구현 때 다시 확인): KBS 2FM 89.1 · MBC FM4U 91.9 · KBS 1FM 93.1 · CBS 음악FM 93.9 · TBS FM 95.1 · MBC 표준FM 95.9 · KBS 1라디오 97.3 · CBS 표준FM 98.1 · SBS 러브FM 103.5 · EBS FM 104.5 · SBS 파워FM 107.7
- 한 지역 안에서 같은 주파수가 겹치거나 0.1 MHz 차이로 붙어 있으면 표시해 고친다.
- 방송국 목록 API(`/radio/stations`)에 `freq`를 그대로 실어 보낸다. DB 마이그레이션은 없다(JSON 파일).

### 2.3 지금 방송 프로그램 (라디오 제목)
- 서버가 방송사의 "지금 방송" 정보를 가져와 1분 동안 보관하고, `GET /radio/stations/{id}/now` → `{ title, start, end }`로 알려 준다. 앱은 튜너 화면과 미니 플레이어에서 2분마다 다시 묻는다.
- 2026-11-12에 확인한 출처:
  - **KBS**: `static.api.kbs.co.kr/mediafactory/v1/schedule/onair_now`(채널 코드별) — 프로그램 이름과 시작·끝 시각이 옴(예: 2FM "이상호의 드림팝 21:00–22:00")
  - **SBS**: `apis.sbs.co.kr/play-api/1.0/onair/channel/{S07 등}` — 프로그램 이름이 옴(예: 파워FM "웬디의 영스트리트")
  - **MBC**: 처음 시도한 주소는 응답이 없어 구현 때 다른 주소를 찾는다
  - **CBS·EBS·TBS·YTN·지역 방송**: 구현 때 하나씩 확인한다. 스트림 안에 곡·프로그램 정보(ICY·ID3)가 실려 오는 방송국은 그것을 쓴다
- 정보가 없는 방송국은 제목 자리에 지역 이름만 보여 준다. 방송사 응답이 늦어도 재생에는 영향이 없다.

## 3. 두 가지 모드

- 라디오 페이지 상단에 **[목록 | 튜너]** 전환 버튼을 둔다. 고른 모드는 기억한다(`ui.views.radioMode`).
- 목록 모드는 지금 그대로다.
- 튜너 모드는 아래 4장의 화면이다. 지역 선택은 두 모드가 함께 쓴다. 튜너의 다이얼에는 고른 지역의 방송국만 놓인다.
- 미니 플레이어, 잠금화면 버튼, 이전/다음 방송국은 두 모드 모두 지금처럼 동작한다.

## 4. 튜너 모드 화면

iPhone의 FM 라디오 앱 같은 깔끔한 레이아웃이다(2026-11-12 요청, 첨부 화면 참고). 큰 주파수 숫자가 가운데 있고, 아래에 가로로 흐르는 눈금 다이얼과 고정된 바늘이 있다. 나무결 케이스, 램프, 7세그먼트는 쓰지 않는다.

```
┌────────────────────────────────────┐
│ 서울 ▾                          ★  │  ← 지역(누르면 바꿈) · 즐겨찾기
│            ┌──────┐                │
│            │ 로고 │                │  ← 채널 이미지(방송국 로고)
│            └──────┘                │
│        91.9 FM                     │  ← 큰 가는 숫자 + 밴드
│          KBS 2FM                   │  ← 방송국 이름
│     이상호의 드림팝 · 21:00–22:00   │  ← 지금 방송 프로그램(라디오 제목)
│        방송국 더 보기 ›             │  ← 목록 모드로
│                                    │
│     ⋯          ☆≡          ⇪      │  ← 더보기 · 메모리 · 공유
│ ┌────────────────────────────────┐ │
│ │ 89   90   91  │92   93   94   95│ │  ← 눈금 다이얼(좌우로 끌어 이동)
│ │ ╵╵╵╵|╵╵╵╵|╵╵╵╵│╵╵╵|╵╵╵╵|╵╵╵╵|╵╵│ │     방송국 자리에 작은 점
│ └───────────────┃────────────────┘ │  ← 가운데 고정 바늘(테마 강조색)
│       ◀◀         ❚❚         ▶▶     │  ← SEEK · 재생/정지 · SEEK
│  🔈 ───────────────●────── 🔊      │  ← 음량(iPhone 제외, 4.3)
│  [1 89.1] [2 91.9] [3 107.7] [4 —] [5 —] [6 —] │  ← 메모리(프리셋)
└────────────────────────────────────┘
```

### 4.1 모양과 테마
- 앱의 테마 색(배경·표면·글자·강조색)을 그대로 쓴다. 바늘, 즐겨찾기 별, 링크, 아이콘이 테마의 강조색이다(기본 테마는 빨강, 멜론·스포티파이 테마는 초록 계열).
- 밝은 테마는 연회색 눈금 띠에 진회색 눈금, 어두운 테마(plexamp·spotify)는 어두운 띠에 밝은 눈금이다.
- 주파수 숫자는 아주 큰 가는 글씨(모바일 96px 안팎, 숫자 폭이 일정한 글꼴)다. 바늘이 움직이면 숫자도 0.1씩 바로 바뀐다.
- 모바일은 위 그림 그대로 세로 한 화면이다. PC는 가운데 정렬로 폭을 제한하고(최대 720px), 눈금 띠만 넓게 쓴다.

### 4.2 표시하는 것
- **채널 이미지**: 방송국 로고(`/radio-logos/<logo>.png`, 지금 목록에서 쓰는 것). 로고가 없으면 지금의 방송사 배지(`StationBadge`). 바늘이 방송국 사이에 있으면 흐리게 표시한다.
- **주파수**: `91.9 FM` / `711 AM`(kHz) / NET 밴드는 `CH 03`
- **방송국 이름**: `KBS 2FM`. 방송국 사이에서는 `—`
- **라디오 제목**(지금 방송 중인 프로그램 이름)과 시간: 2.3에서 가져온다. 길면 흐르는 글자로 보여 준다. 없으면 지역 이름을 쓴다.
- **채널 번호**: 지역·밴드 안 주파수 순 번호(CH 01 …). 이름 옆에 작게 둔다.
- 연결 중일 때는 재생 버튼 자리에 빙글 도는 표시가 나온다.

### 4.3 조작
| 조작 | 동작 |
|---|---|
| 눈금 띠를 좌우로 끌기(스와이프) | 띠가 따라 움직이고 바늘 아래 주파수가 바뀐다. 놓으면 관성으로 미끄러지다가 0.1 단위에 멈춘다 |
| 바늘 아래 주파수가 방송국이면 | 0.4초 뒤 재생한다. 방송국 ±0.1 안이면 정확한 자리로 살짝 끌어당긴다 |
| 눈금 숫자 탭 | 그 주파수로 이동 |
| ◀◀ / ▶▶ | **SEEK**: 다음(이전) 방송국까지 띠가 스르륵 움직이고 재생한다. 끝에서는 반대쪽 끝으로 넘어간다 |
| ◀◀ / ▶▶ 길게 누르기 | **SCAN**: 방송국마다 7초씩 들려주며 돈다. 아무 곳이나 누르면 멈춘다 |
| ❚❚ / ▶ | 정지·재생 |
| 마우스 휠, 키보드 ←/→ | 0.1씩(AM은 9 kHz), Shift와 함께면 1 MHz |
| 음량 막대 | 앱 음량. iPhone은 웹앱이 음량을 바꿀 수 없어(기기 버튼만 됨) 숨긴다 |
| 지역 ▾ | 지역 고르기(목록 모드와 같은 값) |
| ★ | 즐겨찾기(목록 모드의 즐겨찾기와 같은 것) |
| ⋯ | 숨기기, 밴드 바꾸기(FM·AM·NET), 튜닝 잡음 켬/끔 |
| ⇪ 공유 | 방송국 이름·주파수·지금 프로그램을 공유(휴대폰 공유 창) |

- 바늘이 방송국 사이에 있으면 방송을 멈추고, 켜 두었다면 튜닝 잡음을 낸다(4.4).
- 다이얼은 접근성용 슬라이더다(`role="slider"`, `aria-valuetext="FM 91.9, KBS 2FM"`).

### 4.4 튜닝 잡음 (선택)
- 방송국 사이에서 Web Audio로 만든 작은 "치익" 잡음을 낸다. 방송국에 가까워질수록 줄어든다.
- 기본은 **끔**이다. ⋯ 메뉴에서 켠다(`ui.radio.tunerNoise`).
- 튜너 화면을 보는 동안만 낸다. iPhone 백그라운드 재생에 영향을 주지 않게 별도 AudioContext를 쓰고, 탭할 때 만든다.

### 4.5 메모리 (프리셋)
- 밴드마다 **6개**를 둔다. 재생 버튼 아래 한 줄에 칩으로 보이고, 칩에는 번호·주파수·로고가 작게 나온다. ☆≡ 아이콘은 프리셋 전체 목록 창을 연다(이름, 프로그램, 순서 바꾸기, 지우기).
- **불러오기**: 칩을 누르면 그 주파수로 띠가 이동하고 재생한다.
- **저장**: 칩을 **길게 누르면**(0.8초) 지금 주파수가 저장된다. "메모리 3에 저장" 알림과 짧은 진동이 따른다. 빈 칩(`—`)을 누르면 "길게 눌러 저장" 안내가 나온다.
- 저장 위치: `ui.radio.presets = { seoul: { FM: [89.1, 91.9, null, …], AM: [...], NET: ["mbc-chm", …] } }`. 지역별로 두고 계정에 동기화한다(즐겨찾기와 같은 경로).
- 처음에는 그 지역 즐겨찾기 방송국으로 빈 칸을 채워 둔다.

## 6. 확인 방법
- 지역마다 다이얼의 방송국 위치를 공식 주파수와 대조한다(서울·부산은 전부, 나머지는 표본).
- 눈금 띠 스와이프·숫자 탭·휠·키보드로 맞췄을 때 0.4초 안에 해당 방송국이 재생되는지, 방송국 사이에서는 재생이 멈추는지 본다.
- 지금 방송 프로그램이 방송사 편성표와 맞는지 방송사별로 확인한다.
- SEEK이 끝에서 반대쪽으로 넘어가는지, SCAN이 7초씩 돌다가 탭에 멈추는지 본다.
- 프리셋 저장 두 방식과, 다른 기기에서 같은 프리셋이 보이는지(동기화) 확인한다.
- iPhone: 튜너에서 고른 방송국이 화면을 잠가도 계속 나오는지, 잡음은 잠그면 멈추는지, 음량 막대가 숨겨지는지 본다(실기기 확인 필요).
- 모든 앱 테마(default·plexamp·spotify·melon)에서 바늘·별·눈금 색이 어울리는지 스크린샷으로 본다.
- 모바일·PC, 밝은·어두운 테마 스크린샷을 비교한다. 스모크 테스트와 업그레이드 테스트는 매 릴리즈 하던 대로 한다.
