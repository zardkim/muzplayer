# 외부 서비스와 라이선스

## 외부 서비스

muzplayer는 NAS의 파일만으로 동작하지만, 다음 정보는 인터넷의 서비스에서 가져옵니다. 쓰지 않으려면 해당 기능을 끄면 됩니다.

| 정보 | 서비스 | 비고 |
|---|---|---|
| 가사 | 알송, 벅스, LRCLIB | 비공식 연동(알송·벅스) |
| 앨범 소개·별점·벅스 아티스트 이름 | 벅스, 멜론 | 비공식 연동 |
| 아티스트 다른 이름·사진 | MusicBrainz, Wikidata, 위키백과, 벅스 | |
| 라디오 | 각 방송사의 공개 스트림 | 서버가 중계 |
| 뮤직 영상 검색 | YouTube Data API v3 | 관리자가 키를 넣을 때만 |
| 음원 추출 | YouTube(yt-dlp) | **기본으로 꺼짐** |
| AI 배너·곡 정보 찾기 | Gemini 또는 OpenAI | 관리자가 키를 넣을 때만, 요청마다 비용 |

- 비공식 연동은 서비스 쪽 변경으로 동작하지 않을 수 있고, 각 서비스의 약관을 따릅니다. 개인적·비상업적 용도로 쓰세요.
- YouTube 약관은 YouTube가 허용한 경우 외의 다운로드를 금지합니다. 음원 추출은 권리가 있거나 허락된 영상에만 쓰세요.
- 방송사·차트 로고는 각 소유자의 상표이며 방송과 차트를 구분하는 용도로만 표시합니다. muzplayer는 이들과 관계가 없습니다.
