# 개발

## 구조

| 경로 | 내용 |
|---|---|
| `backend/app` | FastAPI 서버(`main.py`), API(`api/`), 스캐너(`scanner.py`), 가사·추출·라디오 등 |
| `backend/alembic` | DB 마이그레이션(앱이 시작할 때 자동 적용) |
| `frontend/src` | Vue 3 + TypeScript + Tailwind 웹 앱, 번역(`locales/ko.json`, `en.json`) |
| `deploy/` | 배포용 `docker-compose.yml`, `.env.example` |
| `scripts/smoke_test.sh` | API 스모크 테스트 |
| `Dockerfile` | 웹 앱 빌드 → 최소 ffmpeg 빌드 → deno → Python 런타임 |

## 이미지 직접 빌드

```bash
docker build --build-arg APP_VERSION=dev -t muzplayer .
```

`.env`에 `MUZPLAYER_IMAGE=muzplayer`, `MUZPLAYER_VERSION=latest`를 넣으면 배포용 compose가 이 이미지를 씁니다.

## 로컬 개발

필요한 것: Python 3.12, Node 24, PostgreSQL 17, ffmpeg.

```bash
# 백엔드
python3.12 -m venv .venv && .venv/bin/pip install -r backend/requirements.txt
export DATABASE_URL=postgresql+psycopg://muzplayer:비밀번호@127.0.0.1:5432/muzplayer
export MUSIC_DIR=/path/to/music DATA_DIR=./dev/data CONF_DIR=./dev/conf COOKIE_SECURE=false
cd backend && ../.venv/bin/python -m app.migrate && ../.venv/bin/uvicorn app.main:app --port 18580

# 프런트엔드 (다른 터미널, /api는 18580으로 프록시)
cd frontend && npm ci && npm run dev
```

주요 환경 변수: `DATABASE_URL`, `MUSIC_DIR`, `AUDIOBOOK_DIR`, `VIDEO_DIR`, `EXTRACT_DIR`, `DATA_DIR`, `CONF_DIR`, `STATIC_DIR`(빌드한 웹 앱), `FFMPEG_PATH`, `DENO_PATH`, `SCAN_INTERVAL_MINUTES`, `TRANSCODE_CACHE_MB`, `SESSION_DAYS`, `DEFAULT_LOCALE`, `COOKIE_SECURE`.

## 테스트

```bash
cd frontend && npm run build                 # 번역 키 검사 + 타입 검사 + 빌드
bash scripts/smoke_test.sh http://127.0.0.1:18580 <관리자> <비밀번호> /path/to/music
```

스모크 테스트는 관리자 계정이 있는 서버에 가입·스캔·재생·플레이리스트·가사·추출 등을 차례로 호출해 확인합니다(테스트용 서버에서만 실행하세요).
