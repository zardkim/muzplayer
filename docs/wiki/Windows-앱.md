# Windows 앱

PC에서는 브라우저로도 쓰지만, Windows 앱을 설치하면 브라우저로는 안 되는 기능이 더해집니다. 앱은 muzplayer 서버의 웹 화면을 그대로 띄우는 전용 클라이언트입니다.

- **트레이:** 창을 닫아도 트레이에서 계속 재생. 트레이 메뉴(재생·일시정지·다음·이전·열기·서버 바꾸기·종료), 툴팁에 지금 곡
- **전역 단축키:** 다른 프로그램을 쓰는 중에도 Ctrl+Alt+Space(재생/일시정지), Ctrl+Alt+→/←(다음/이전). 연결 화면에서 바꾸거나 끔
- **미디어 키와 Windows 미디어 카드**, 작업 표시줄 진행 막대
- **바로 업데이트:** 서버의 설정 → 홈 화면에 추가에서 새 버전이 있으면 **지금 업데이트**(앱 0.3.0 이상)

## 설치

1. 서버에 브라우저로 접속해 설정 → **홈 화면에 추가**에서 Windows 앱 설치 파일을 받습니다.
2. `muzplayer-<버전>-x64.exe`를 실행합니다(관리자 권한 불필요, 사용자 폴더에 설치). 코드 서명을 하지 않아 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다.
3. 처음 열면 서버 주소(예: `https://music.example.com` 또는 `192.168.0.10:18150`)를 넣고 연결합니다. 서버는 하나만 등록되고, 연결 화면에서 바꾸거나 지울 수 있습니다.

설정 파일: `%APPDATA%\muzplayer\settings.json`

서버가 직접 만든 https 인증서를 쓰면 연결할 때 확인 창이 뜨고, 그 인증서만 신뢰합니다.
